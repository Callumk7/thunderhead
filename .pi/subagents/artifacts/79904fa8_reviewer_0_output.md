## Review

- **High — Raw Linear issue secrets reach the model before redaction.** `src/channels/linear.ts:41` inserts the unredacted title into the agent message, while `src/tools/linear-issue.ts:249-256` returns the unredacted title and description. Redaction occurs only on proposed output at `src/tools/linear-issue.ts:99-103`. Credentials pasted into an issue are therefore disclosed to the model. **Smallest fix:** redact all model-facing issue text and replace the raw expected title/description parameters with an opaque server-bound snapshot token or digest for conflict validation.

- **High — Standard encrypted private keys bypass repository redaction.** The private-key expression at `src/shared/secret-redaction.ts:2` does not match `-----BEGIN ENCRYPTED PRIVATE KEY-----`; an allowed path such as `fixtures/encrypted-private-key.txt` consequently reaches the model through `src/tools/repository-read.ts:137-144`. **Smallest fix:** cover encrypted PKCS#8 and other supported private-key headers with paired begin/end matching, and add regression tests.

- **High — Repository authorization state is not bound to repository identity.** File-read count, failures, and discovered paths are keyed only by delivery at `src/agents/issue-strengthener.ts:47-57`, and readiness uses only the stale count at `src/agents/issue-strengthener.ts:72`. If a durable workflow resumes after its team mapping changes, a read from repository A unlocks publication under repository B, while paths discovered in A authorize reads in B through `src/tools/repository-read.ts:23,108`. **Smallest fix:** namespace or store discovery/read/failure state with the normalized current `owner/repo` identity and reset/reject state on identity mismatch.

No additional blocker/high-severity defect was identified in label restrictions, issue binding, trigger-removal publication cancellation, or fixed-repository tool scoping. Prompt injection remains bounded to the mapped repository tools and one bound Linear issue, but can still influence that issue’s structured content and additive existing labels.
